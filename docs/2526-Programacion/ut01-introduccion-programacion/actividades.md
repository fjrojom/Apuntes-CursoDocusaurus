¡Es hora de ensuciarse las manos con código! Aquí tienes una serie de retos para practicar todo lo que hemos aprendido en esta unidad. Recuerda que la programación es una habilidad que se adquiere practicando.

## ¿Qué vamos a practicar?
*   Declaración de variables y elección de tipos.
*   Cálculos aritméticos y precedencia.
*   Uso de constantes para valores fijos.
*   Conversión de tipos.

:::info Instrucciones
1.  Abre **PSeInt**.
2.  Crea un nuevo archivo para cada ejercicio.
3.  Ponle un nombre descriptivo al algoritmo (ej: `Algoritmo CalculadoraSimple`).
4.  ¡No olvides comentar tu código para explicar qué hace cada parte!
:::

---

## Reto 1: El Supermercado
Crea un programa que pida al usuario el nombre de un producto, su precio base y la cantidad de unidades que desea comprar. El programa debe mostrar el total a pagar.

*   **Pista**: Necesitarás variables de tipo `Caracter`, `Real` y `Entero`.

## Reto 2: Conversor de Temperatura
Escribe un programa que convierta una temperatura dada en grados Celsius a Fahrenheit.
*   **Fórmula**: `F = (C * 9/5) + 32`
*   El programa debe pedir los grados Celsius y mostrar el resultado con un mensaje descriptivo.

## Reto 3: La Constante de Descuento
Imagina que trabajas en una tienda que siempre aplica un descuento del 15% por ser la semana de inauguración. 
1.  Define una **constante** `DESCUENTO <- 0.15`.
2.  Pide el precio de un artículo.
3.  Calcula el ahorro conseguido y el precio final.
4.  Muestra ambos resultados por pantalla.

## Reto 4: Verificador de Discoteca (Lógica)
Queremos un programa que decida si una persona puede entrar a una discoteca. Para entrar debe:
*   Ser mayor de edad (18 años o más).
*   **Y** tener una entrada válida (`Verdadero`/`Falso`).

El programa debe pedir la edad y si tiene entrada, y mostrar al final un valor lógico (`Verdadero`/`Falso`) indicando si puede pasar.

## Reto 5: El "Mago" de los Números (Conversión)
Crea un programa que pida al usuario un número con decimales (Real). El programa debe:
1.  Mostrar el número original.
2.  Convertir ese número a entero (truncarlo) y mostrar el resultado.
3.  Mostrar la parte decimal que se ha "perdido" en la conversión.
    *   *Pista: resta el número entero al número original.*
