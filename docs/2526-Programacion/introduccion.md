# Programación 1º DAW (Java)

¡Bienvenido al módulo de **Programación**! Este es uno de los pilares fundamentales del ciclo formativo de Grado Superior en **Desarrollo de Aplicaciones Web (DAW)**. Durante este curso, nos sumergiremos en el fascinante mundo del desarrollo de software utilizando **Java**, uno de los lenguajes más potentes, versátiles y demandados en la industria actual.

## ¿Qué vamos a aprender?

El objetivo principal de este módulo es que adquieras las habilidades necesarias para diseñar y desarrollar aplicaciones robustas, eficientes y mantenibles. A lo largo del curso, cubriremos los siguientes bloques temáticos:

1.  **Fundamentos de Programación**: Tipos de datos, variables, operadores y estructuras de control (bucles y condicionales).
2.  **Programación Orientada a Objetos (POO)**: Clases, objetos, herencia, polimorfismo y encapsulamiento.
3.  **Estructuras de Almacenamiento**: Gestión de arrays, listas (ArrayList) y otras colecciones de datos.
4.  **Manejo de Excepciones**: Cómo hacer que nuestras aplicaciones sean resistentes a errores.
5.  **Persistencia de Datos**: Lectura y escritura de información en ficheros y bases de datos.
6.  **Interfaces Gráficas (GUI)**: Creación de aplicaciones visuales para el usuario.

## ¿Por qué Java?

Java es un lenguaje **multiplataforma** ("Escribe una vez, ejecuta en cualquier lugar") que se utiliza en una gran variedad de entornos: desde aplicaciones empresariales y servidores web hasta aplicaciones móviles (Android) y sistemas embebidos. Aprender Java te proporcionará una base sólida que te facilitará el aprendizaje de otros lenguajes modernos.

## Herramientas de Trabajo

Para desarrollar nuestras aplicaciones, utilizaremos un entorno profesional:

*   **Java Development Kit (JDK)**: El motor que nos permite compilar y ejecutar código Java.
*   **IDE (Entorno de Desarrollo Integrado)**: Utilizaremos herramientas como **IntelliJ IDEA** o **Eclipse**, que nos ayudan a escribir código de forma más rápida y sin errores.
*   **Git**: Para el control de versiones de nuestros proyectos.

## Consejos para el Éxito

La programación no se aprende solo leyendo; se aprende **programando**. Mi consejo principal es que practiques a diario, no tengas miedo a que el código falle (de los errores es de donde más se aprende) y busques siempre entender el *porqué* de las cosas, no solo el *cómo*.
